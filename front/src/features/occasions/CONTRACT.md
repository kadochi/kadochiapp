# Occasions contract

All occasion methods go through explicit same-origin `/api/occasions` routes and the protected WordPress API. Public occasions are created by WordPress administrators and returned to every authenticated user; personal occasions are returned only to their owner. Inputs exclude owner/user IDs, data is `no-store`, and mutations are never retried. Personal occasions can be annual (`repeatsAnnually`, defaulting to `true`) and only their owner can update or delete them. Updates/deletes require a version for optimistic concurrency; deletion moves the record to WordPress trash (rollback-safe retention policy). Authentication is unavailable until the selected `wordpress-cookie` bridge has been verified.
